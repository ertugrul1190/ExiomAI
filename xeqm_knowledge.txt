XEQM / EXIOM OFFICIAL KNOWLEDGE

Exiom is a privacy-focused Proof-of-Stake blockchain network and developer platform built by XEQMLabs.

The coin used by the network is XEQM.

Exiom was formerly called Equilibria, whose ticker was XEQ. Equilibria/XEQ is the old name. After the Horizon migration, the coin became XEQM and the network/platform became Exiom.

CORE PURPOSE

Exiom's main goal is to make privacy programmable.

Instead of privacy only being used for sending private cryptocurrency transactions, developers can use Exiom's platform to add privacy features to applications.

Examples include:
- private identity verification
- private data
- private communications
- private access control
- private payments/value transfers

XEQM

XEQM is the privacy coin, utility coin and access asset of the Exiom ecosystem.

Developers can stake XEQM to access different levels of the developer API.

XEQM uses Monero-based CryptoNote cryptography, including privacy technologies such as ring signatures, stealth addresses and confidential transaction amounts.

Exiom is its own network and should not simply be described as a Monero clone.

CONSENSUS

Exiom uses pure Proof-of-Stake.

Service nodes help secure and operate the network.

SERVICE NODE STAKING

A full service node requires a total stake of 200,000 XEQM.

SOLO NODE:
A solo operator provides the full 200,000 XEQM.

SHARED / POOLED NODE:
A shared node still requires 200,000 XEQM in total.

The operator who creates the shared node must personally stake at least 100,000 XEQM.

Community contributors can provide the remaining amount.

The minimum community contribution is 10,000 XEQM per contributor slot.

A shared node can have up to 10 community contributor slots in addition to the operator.

IMPORTANT — DO NOT CONFUSE THESE AMOUNTS:
- 200,000 XEQM = total stake required for one service node
- 100,000 XEQM = minimum stake required from the operator creating a shared node
- 10,000 XEQM = minimum community contribution per slot for someone joining a shared node

DEVELOPER PLATFORM

Free:
No XEQM stake.
10,000 testnet API calls per month.

Builder:
1,000 XEQM staked.
100,000 mainnet API calls per month.

Production:
10,000 XEQM staked.
1,000,000 API calls per month plus webhooks.

Enterprise:
50,000 XEQM staked.
Unlimited calls and SLA/custom limits.

Staking for API access is intended as a commitment rather than a fee. The developer retains ownership of the staked XEQM and can unstake.

PLATFORM FEES

Platform fees are distributed:
35% to API node operators
35% to the XEQMLabs treasury
30% to community governance

BACKGROUND

XEQM has more than seven years of operating history.

It originally operated as the Proof-of-Work Equilibria/XEQ chain and later migrated to the pure Proof-of-Stake Exiom network through the Horizon upgrade.

The current mainnet is called Ragnarok.

The project describes the Horizon migration as "no trust required" and provides publicly verifiable migration information.

PRIVACY

Transactions are designed not to reveal the sender, receiver or transaction amount.

Exiom's major differentiator is that it aims to make privacy available to developers through programmable APIs rather than limiting privacy to wallet transactions.
